# 小白狼

## 基本信息

- **名称**：小白狼
- **种族**：狼族
- **性别**：雌性
- **身世**：来历不明，失魂落魄时被南方狼村的村长捡走收养
- **时代**：黑暗时代中后期
- **状态**：已死亡

## 外貌特征

### 本体形态
- **毛色**：纯白色，毛发光洁柔顺
- **体型**：相比普通狼族更加娇小

## 重要经历

### 收养与村庄生活
- **被捡收养**：被南方狼村的村长发现并捡走收养
- **融入新家**：成为该狼村的一员，并与同为孤儿的狼族少年相遇
- **共通背景**：两人都是孤儿，都被村长收养，这成为他们建立深厚情感的基础

### 与狼族少年的关系
- **青梅竹马**：与狼族少年从小相识，关系亲密
- **共同经历**：一同度过多年时光，建立了深厚的情感联系

### 死亡事件
- **时间**：奴隶队袭击村庄时期
- **死因**：被一支**普通的铁矛**刺死
- **死亡影响**：她的死亡是狼族少年爆发、开启"狼灾时期"的导火索之一
