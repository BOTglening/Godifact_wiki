# 古斯塔夫（龙王）

## 基本信息

- **名称**：古斯塔夫，也被称为"龙王"
- **称号**：龙王
- **所在地**：龙族隐居地——山体呈独特的"锤头"状
- **状态**：仍在履行其守护龙族的职责

## 化身形象（民间流传）

- **形态**：传说中，龙王有时会以一只**灰色皮肤、蓝色眼睛的小狼族兽人**的形象现身
- **体型特征**：为青少年，便于活动而不引起对龙王的联想
- **行为模式**：能够模拟狼族的行动和社交方式

## 与龙族的关系

### 守护者角色
- **深爱龙族**：对龙族怀有深厚的感情和责任
- **约束管教**：负责约束龙族行为，避免引发更大危机
- **居中协调**：在龙族与外界之间协调

### 龙族的隐居
龙族曾存在于文献与史书中，却不知何时忽然消失。大陆上仍有关于龙的身影的目击传说在流传，真假难辨；而"锤头山"之名，仅存于传说之中，其位置始终无人能够确证。
