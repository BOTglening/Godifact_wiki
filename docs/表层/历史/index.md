# 表层历史

## 概念诠释

表层历史记录福瑞种族所经历和传承的历史事件。从共同体建立至今，这段历史是大陆生灵共同记忆的核心。

## 历史时期划分

### 1. 共同体时期

神明"红星"带领智慧生灵脱离蒙昧、建立共同体的时期，历时约两百年。

> **详细内容参见**：[共同体时期](共同体时期.md)

### 2. 黑暗时代

共同体解体后约200年的至暗时期。新五族垄断魔法、推行奴隶制。

> **详细内容参见**：[黑暗时代](黑暗时代.md)

### 3. 当前时代

黑暗时代结束后形成的冷战格局时代，以鹿族与熊族的两极对峙为核心。

> **详细内容参见**：[当前时代](当前时代.md)
