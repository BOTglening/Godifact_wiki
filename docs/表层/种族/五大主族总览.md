# 五大主族总览

## 概述

五大主族为共同体时期的核心五族——牛族、鹿族、鹤族、熊族、甲族，共同体旗帜上的五颗星分别代表这五个种族。但共同体时期的种族不止五个，鸽族、鹰族、狮族等其余多个种族也存在于共同体之中。

## 五大主族一览

### 牛族——农业担当

牛族的种族核心特质是**耐心与求稳**。共同体时期负责农业相关的一切，为整个文明提供粮食基础。黑暗时代中，牛族成为**首个彻底沦为奴隶的种族**，曾试图抵抗新五族的压迫，但被法师以绝对力量镇压至近乎灭绝，剩余族人彻底丧失主权，成为流亡种族。当代牛族隐居，族群规模极小，与兔族、鹤族联系紧密。

### 鹿族——科研担当

鹿族的种族核心特质是**好奇心与求知欲**。共同体时期负责科研相关的一切，是五大主族之首。黑暗时代中鹿族沦为法师的助手/宠物，此后重新崛起。当代鹿族为**世界一极**，拥有全大陆最先进的科技水平，当前与熊族处于冷战对峙之中。

### 鹤族——政治担当

鹤族的种族核心特质是**总体思考与大局观**。共同体时期负责政治相关的一切，但在神明掌握实权的情况下，仅承担传递神明信息与基层管理工作，严重缺乏顶层策略制定的实践经验，执政威信不足。共同体解体后鹤族隐居山林，族群规模极小。

### 熊族——工业担当

熊族的种族核心特质是**建设与发展欲**。共同体时期负责工业相关的一切。共同体末期内斗中熊族被鹿族排挤，此后举族北迁至北境恶劣地带，生活质量长期低下。当代熊族为**世界一极**，拥有全大陆最先进的工业水平，数百年来保持着红色的旗帜与五星的一角作为标志，无比怀念共同体时期，渴望南下光复故土。当前与鹿族冷战对峙。

### 甲族——军事担当

甲族的种族核心特质是**服从与执行力**。共同体时期负责军事相关的一切，旧时代国防军几乎全由甲族组成。甲族目前已**近乎灭绝**：灭绝原因无人记载（相关记录被刻意抹除），幸存者以个计数，其中一位长期做客于红星孤儿院。甲族的繁衍与生活习性与其他种族差异极大，过去一度被外界视为"畸形怪种"。

## 当代格局

五大主族在当代已分化为两极对峙格局：鹿族与熊族各自成为世界一极，牛族与鹤族隐居山林，甲族近乎灭绝。
