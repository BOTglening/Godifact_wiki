# 种族总览

## "人"的概念

当前世界的所有智慧生灵都被纳入统一的称呼范畴——**"人"**。"人"指拥有高级思考能力与复杂感情的、可双足直立行走的生灵。

这一概念由神明统一赋予：在此基础上，根据外貌特征加前缀命名，如鹿人、熊人。这一举措打破了种族隔阂，赋予不同生灵统一的身份认同。

## 种族大类

当前世界的智慧生灵可分为两大核心大类，另有若干独立种族与传说种。

### 羽族

体格普遍偏小，骨骼轻盈且强度极高，部分分支背后生有双翅，具备飞行能力。其下分为三族：

- **鹰族**：羽族中体格最健壮，羽毛颜色偏深棕。
- **鸽族**：羽族中体格偏小，羽毛多为洁净的白色。
- **鹤族**：羽族中体质最弱小，羽毛以白为主、黑为辅；飞行高度与耐力最佳。

### 兽族

大陆数量最多的种族大类，为典型福瑞形态，包含多个种族。

- **狼族**：兽族中较为新兴的种族，体格中等，看起来有点傻傻的，但作为新兴的主族，其实力不可小觑。
- **鹿族**：兽族中历史悠久的种族，体格中等，头有鹿角，充满好奇心与探索欲，作为老牌主族，底蕴深厚。
- **熊族**：兽族中历史悠久的种族，体格健壮，多是实干家，工业实力强劲，作为老牌主族，底蕴深厚。
- **兔族**：兽族中较为新兴的种族，体格偏小，多居住于林中，整体较为松散，喜欢平静的生活。
- **狐族**：兽族中较为新兴的种族，体格偏小，整族全雌，学习能力强，与狼族有深厚的友谊。

### 其他独立种族

- **甲族**：非毛系种族，生存习性与其他种族差异极大，如今近乎灭绝。
- **精灵族**：唯一长得像人的种族，尖耳朵、白袍与法杖是其特征。

## 种族格局

### 现存主要种族

- **三大主族**：鹿、熊、狼——当今的三个主要种族，作为世界三极，都具有强大且独立的种族实力，是当今世界舞台之上毫无疑问的主角。
- **其余副族**：狐、兔、鹰、鸽、蜥等，多在黑暗时代前后登上历史舞台。
- **传说种**：龙、猫、焰种——是否仍存于世并不确定，往往十分独特且强大。

### 已亡种族

猪族、蝠族、鼠族、虎族、豹族——已在历史中彻底消亡。

### 流亡/丧失主权的种族

牛族、羊族——或因迁徙而流亡，或已丧失主权。
