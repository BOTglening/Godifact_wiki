# 地理环境

## 概念诠释

地理环境部分描述神造物世界中智慧生灵所生活的大陆地貌、自然环境与古代遗迹的位置分布。

## 主要内容领域

### 1. 自然生态

大陆的自然地理环境，包括森林、草原、山脉等地貌特点以及各族群在其间的生存方式。

> **详细内容参见**：[自然生态](自然生态.md)

### 2. 古代遗迹

描述遍布大陆的古代遗迹，包括其形态特征与危险。

> **详细内容参见**：[古代遗迹](古代遗迹.md)

## 阅读建议

1. **先了解表层设定框架**：建议先阅读种族总览与表层历史，再了解具体地理细节
2. **注意深层联系**：许多真相都埋藏在深层设定之中
