# 古代遗迹

## 梯形神殿废墟（旧都）

共同体时期的梯形神殿是共同体的政治中心与神明居所。灾变中，神殿被炸翻，旧都随之沉入水下，如今只剩下沉没于水下的废墟。

## 旧都水下之城

共同体首都于灾变中地面下沉、河水涌入，短短数日内沦为**水下之城**。如今整座城市沉没于水域之中，成为一片水下遗迹。

## 大陆上的古环形山

大陆上随处可见或大或小的环形山，被普遍视为自然地形地貌。然而其规整的形态令人生疑——看起来的确不像是自然形成的。至于其真正的来历，无人能够解释。

> **详细内容参见**：[正传历史](../../中层/历史/正传历史.md)

## 六边形沙漠

大陆上一片诡异的沙漠，呈规则的六边形几何特征，温度奇高且逐年升温，逐渐成为无活物可生存的无人区。其形成原因不明。

## 通天光柱

大陆某处有一道通天彻地的纯白光柱，天空在扭曲，大地被撕裂。没有人知道发生了什么，更没人知道光柱底下那些奇奇怪怪的构筑物是什么，因为没有人能活着靠近那根光柱。

> **详细内容参见**：[前传超算纪元](../../中层/历史/前传超算纪元.md)
