# 自然生态

## 六边形沙漠

大陆上一片看起来不像是自然形成的诡异沙漠，呈规则的六边形几何特征，温度奇高，与周边环境差异鲜明，且近百年持续升温，逐渐成为无活物可生存的无人区。沙漠深处岩石层内有极其危险的橙黄色高能晶体矿物，被狮族作为极高能炸药与极高能燃料使用。

## 极北之地

熊族的家园，环境恶劣，低温与土壤条件均不佳，农业发展严重受限，粮食供应长期紧张，但工业资源丰厚，支撑着熊国强大的工业体系。

## 古环形山

大陆上随处可见或大或小的环形山，被普遍视为自然地形地貌，但看起来的确不像是自然形成的。

## 南方深山密林

兔族的栖息地，位于大陆南方。此地道路难行、瘴气弥漫、极易迷路，大规模武装进入的成本与收益完全不成比例，是兔族在黑暗时代得以保持相对独立的地形壁垒。

## 旧都水域

共同体旧都沉没后形成的水域，曾经的繁华都城如今沉睡于水面之下，是大陆上著名的水下遗迹。

## 锤头山

传说中龙族的隐居之地。龙族曾见于文献甚至史书之中，却不知何时忽然消失，如今不再现世，寻找者往往无功而返。"锤头山"之名仅存于传说之中，其位置始终无人能够确证。
