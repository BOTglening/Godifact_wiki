# 表层设定

## 三层结构

神造物世界观分为三个认知层面：**表层设定、中层设定和底层设定**。

- **表层设定**：福瑞种族可直接认知的表象世界，包括种族、地理环境与表层历史。
- **中层设定**：揭示世界表象背后的真相、技术内涵与深层关联。
- **底层设定**：世界观最底层的核心逻辑，包括神权体系、基底层与现实世界的关系。

> 详见：[中层设定](../中层/index.md)、[底层设定](../底层/index.md)。全站链接带层级徽标（[表层]/[中层]/[底层]），随时可以下潜或返回。

## 概念诠释

表层设定是神造物世界观中的**表面认知层面**，也是福瑞种族所认知的世界。这一层面包含大陆上各智慧生灵所能接触和理解的直接现实。

表层是整个世界观叙事的"正门"——读者首先接触的就是这一层面。但这并不意味着表层的设定是虚假的；阳光、友谊与冒险都是真实、确切的。只是在它们之下，还藏着更多的东西。

## 定位与特点

**核心定位：**
- **叙事的正面**：作品初期呈现的经典福瑞奇幻冒险世界
- **真实的一部分**：表层的美好并非伪装，而是这个世界真实的一部分
- **剥洋葱的起始层**：从表层开始，逐渐向深层发掘

**主要特点：**
- **直观可感**：福瑞种族可直接感知、接触、理解的事物
- **可记录**：表层历史、地理、种族特征均可被大陆生灵记录和传承
- **带有多重解释**：同一现象在更深的层面可能有完全不同的解释

## 主要内容领域

### 1. 种族设定

包括各福瑞种族的生理特征、种族特质、历史地位与当代现状。

> **详细内容参见**：[种族设定](种族/index.md)

### 2. 地理环境

大陆的自然环境、生态特点以及遍布各地的古代遗迹。

> **详细内容参见**：[地理环境](地理/index.md)

### 3. 表层历史

福瑞种族所经历的历史事件记录，从共同体时期到当前时代。

> **详细内容参见**：[表层历史](历史/index.md)

### 4. 众生录（表层人物）

从表层视角认识这个世界的人物——红星孤儿院的院长与孩子们、传说中的龙王、鹿族高层，以及他们公开可见的一面。

> **详细内容参见**：[众生录](人物/index.md)

## 与世界观其他层面的关系

### 与中层设定的关系
- **表象与真相**：中层设定揭示表层现象背后的真正原因与机制
- **认知局限**：福瑞种族无法直接认知中层设定的内容

### 与底层设定的关系
- **现象与本质**：底层是世界的规则层面，表层是这些规则的具体表现
- **规则影响**：底层规则无声地塑造着表层世界，其具体机制属于更深层的设定

## 阅读建议

1. **从这里开始**：表层设定是了解神造物世界观的最佳起点，建议按「种族总览 → 表层历史 → 种族设定 → 地理环境 → 众生录」的顺序一路读下去（先读历史，各族档案中反复出现的黑暗时代、共同体才有上下文）
2. **注意伏笔**：表层设定中暗含诸多指向更深层设定的伏笔与线索
3. **保留"表层视角"**：阅读时尽量保持故事中普通生灵的认知视角
4. **带着疑问下潜**：读完表层后，你或许会对"地脉是什么""神明从哪里来""龙族为何消失"充满疑问——这些答案在中层设定与底层设定中，跟着徽标走即可
