# 叙事与伏笔

本目录管理神造物世界观中的**伏笔系统**：将设定中的未解之谜统一编号（F-xx），按"洋葱层"分类维护。它同时是**跨层导航中枢**——无论你在表层、中层还是底层读到哪个谜团，都可以回到这里，跟随层级徽标前往真相所在。

## 洋葱层结构

伏笔按可见程度分为三层：

- **表层伏笔**：福瑞生灵能够察觉到的异常现象（如地脉的光芒、甲族灭绝的空白记录）。
- **中层伏笔**：涉及隐藏真相的谜团（如克隆仓库、上位毁灭神的本源）。
- **底层伏笔**：元规则层面的未解之谜（如玩家能力的本质、叙事逻辑的存在）。

## 使用方法

- 伏笔在文中以 `[伏笔:F-xx]` 标记，指向下方清单。
- 伏笔清单仅记录"谜面"与状态，不记录揭晓方案。
- 状态分为：**未揭晓**（尚无人知晓答案）、**部分揭晓**（真相存在但未完全公开）、**已揭晓**（真相已写入设定文档）。

> **详细内容参见**：[伏笔洋葱层分类](伏笔洋葱层分类.md)
