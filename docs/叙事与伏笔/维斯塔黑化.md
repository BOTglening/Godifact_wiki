# 维斯塔黑化支线（平行时间线）

本支线为平行时间线节点：源自间章神机黑化的分支。若玩家在间章时期的选择不足、未能做到某些事情，神机会彻底黑化、彻底失控，产生与正传正好相反的世界线；此线中维斯塔彻底黑化，成为"赤色暴君"。

## 来源

维斯塔黑化的平行时间线，来源于**神机黑化的部分**（间章部分）。

**关键认知**：
- 在间章很大一部分时间线中，**神机的发展会受主角影响**
- 神机的黑化在官方时间线中是"正常的，可控的"
- 但在玩家选择的其余支线中，情况会不同

## 触发条件

如果玩家在当时的选择不够、没有做到某些事情：
- 神机会**彻底黑化、彻底失控**
- 产生与正传**正好相反**的世界线

## 黑化维斯塔的形象

在这个相反的世界线中：
- **维斯塔彻底黑化**，变成"赤色暴君"
- 维斯塔黑化后同样追求进取，但**更加务实，也更加残暴**
- 不像神机黑化后会谨慎，维斯塔更加极端、更加不顾代价
- **但本质上是主线神机的"同位体"，定位都为"守护者"角色**

## 力量对比

- 执念的能量**比神机的不断进步更大**
- 黑化后的维斯塔**非常非常强大**
- 积极入世，统治着十分庞大的势力

## 统治方式

黑化维斯塔的统治：
- **民众狂热、极端、忠诚**
- **不择手段**
- 不再是"正义的"
- 他**控制了三神权**：
  1. 他自己的变化神权
  2. 剥离控制了毁灭神的神权
  3. 强行继承了创造神的神权（并非神机的神权，此处为下位创造，而非神机的上位创造）

## 目的

黑化维斯塔的核心目的是：**把神机救回来**

## 实现方式

1. 从支线并入主线
2. 来到主线世界
3. **为什么要并入主线**：支线的剧情已经结束了，叙事的力量不复存在
4. 他需要借助**叙事的力量**——因为叙事才有奇迹
5. 让自己出现在主线中，让故事继续下去，让自己的目光被叙事注意到
6. 最终目的是**复活神机**
