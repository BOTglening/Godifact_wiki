# 上位毁灭神（小白狼）

## 基本信息

- **名称**：通常称为"上位毁灭神"或"小白狼"
- **身份**：上位毁灭神权的初代载体
- **外观**：雌性，毛色为白色，体型娇小
- **身世**：原非当前狼族聚落成员，家乡在一次神权失控中被完全抹除
- **收养经历**：失魂落魄时被当前狼族聚落的村长捡走收养
- **特质**：深知自身神权的极端危险性，性格谨慎而富有责任感
- **时代**：黑暗时代中后期
- **状态**：已死亡，但意识与神权残余仍存在于原家乡的深坑中

## 外貌特征

### 本体形态
- **毛色**：纯白色，毛发光洁柔顺
- **体型**：相比普通狼族更加娇小
- **眼睛**：受神权影响为白瞳，在使用神权时会发光
- **特殊标记**：身上可能带有毁灭神权的微弱印记，但外表难以察觉

### 神环形态

- **形态描述**：一个纯白色的巨大发光圆环
- **象征意义**：象征删除，句号，结束，关闭
- **嵌套关系**：可以套住创造与变化的神环，体现着其足以删除一切的权柄

## 毁灭神权特质

### 神权本质
作为上位毁灭神权的载体，她掌握着毁灭神权的底层版本：
- **删除能力**：字面意义上的删除一切，无论是否合理，极端危险，能够删除任何存在，包括物质、能量、概念
- **悖论特性**：神权本身存在逻辑悖论，无法完全删除自身

### 自我认知与限制
上位毁灭神对自身神权有着清醒的认知，这种认知源于亲身经历的巨大悲剧：

1. **危险性认知**：因亲自体验过神权失控的毁灭性后果（家乡被完全抹除），她比任何人都更了解其破坏力
2. **自我限制**：基于对悲剧的恐惧和对他人安全的责任感，主动限制神权的使用
3. **道德约束**：怀有强烈的道德感和内疚感，不愿再让任何人经历她所造成的那种悲剧

## 重要经历

### 神权失控与家乡抹除
**事件概述**：在一次使用神权时，小白狼因未能成功控制毁灭力量而**彻底抹除了自己的家乡**。

- **失控过程**：神权力量意外爆发，超出可控范围
- **抹除结果**：整个村子完全消失，原地只剩下一个**巨大的圆形的坑**
- **地形特征**：坑洞边缘光滑，深不见底，是毁灭神权完全作用的产物
- **心理影响**：这一事件成为小白狼**最底层的心理创伤**，深刻地影响了她的性格和行为

**后续经历**：
1. **失魂落魄**：事件后小白狼在荒地上失魂落魄地游荡
2. **被捡收养**：被当前狼族聚落的村长发现并捡走收养
3. **融入新家**：成为该狼族聚落的一员，并在后来与同为孤儿的**下位毁灭神（主角）**相遇
4. **共通背景**：两人都是孤儿，都被村长收养，这成为他们建立深厚情感的基础

### 早期活动
- **限制神权**：经历家乡抹除事件后，小白狼走向限制，禁用神权的极端
- **自我毁灭尝试**：因深感神权危险性和内心创伤，曾回到原家乡的深坑旁尝试自我毁灭以彻底删除神权
- **悖论失败**：因神权逻辑悖论（无法彻底删除自身）而未能完全成功，其只需小白狼主动停止自删除过程，就会完全回归。自删除尝试的地点为原家乡的深坑旁，象征着她试图在悲剧起点终结一切。

### 与下位毁灭神的关系
- **青梅竹马**：与下位毁灭神（主角，灰色狼）从小相识，关系亲密
- **互相认知**：双方都知道对方的身份和神权特质
- **劝诫与引导**：曾试图劝主角限制自身的神权，教导其谨慎使用力量
- **共同经历**：一同度过多年时光，建立了深厚的情感联系

### 死亡事件
- **时间**：奴隶队袭击村庄时期
- **死因**：被一支**普通的铁矛**刺死
- **武器特性**：这支铁矛本身并无特殊之处，只是普通的武器
- **摒弃神权**：掌握毁灭神权的存在，即使是面对死亡也不愿动用自己的神权，最终死于最普通的武器
- **死亡影响**：她的死亡成为引爆主角仇恨、促使主角登神的**导火索之一**

### 死后影响
- **武器转化**：刺死她的铁矛后被主角持有，在无尽的杀戮中侵染了毁灭神力，成为标志性武器
- **情感驱动**：她的死亡为主角的角色弧光增添了悲情的言情色彩
- **残余状态**：小白狼的意识与神权残余皆存在于原家乡的深坑中。这个巨大圆形的坑洞既是悲剧的印记，也是她存在的最后痕迹。
- **深层联系**：深坑不仅保留了毁灭神权的残留力量，也封印着小白狼未完全消散的意识，形成了一个特殊的空间节点。

## 深层设定（中层真相）

> **中层真相**：以下内容为表层生灵无法知晓的真相。

### 与狼族的深层关联
- 上位毁灭的残留/本源出现在狼族地盘**并非偶然**，与**狼族的基因锁、主角作为下位毁灭神载体**等设定存在深层联系
- 其"根"很可能埋藏在狼族起源或核心区域，是神机布局的一环

### 毁灭神权谱系
- **上位**：初代载体小白狼 → 死后神权残余+意识存于家乡深坑（本源，特殊空间节点）→ 正传中以**龙鹿寻得继承**为关键线
- **下位**：狼族少年（初代下位毁灭神）→ 太空克隆仓库稀释 → 神权回流伏笔
- **分支**：小狼史诗为毁灭神权分支继承（构思中）；三条线交叉于狼族起源区域，是神机布局的一环
