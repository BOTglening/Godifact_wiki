# 初代变化神

## 基本信息

- **名称**：作为人类无固定姓名，通常称为"初代变化神"
- **身份**：初代变化神，现实世界的完善者
- **种族**：人类
- **时代**：从人类原始社会至前传超算纪元
- **所处空间**：基底层（自我禁锢）
- **状态**：意识在基底层中自我禁锢，监管上位变化神权

## 角色概述

初代变化神是变化神权的初代载体，也是现实世界的重要完善者。他作为人类从原始社会时期开始就承载着变化神权，伴随着人类走完了整个文明史。在此期间不断探索宇宙与自身，并深入探究过基底层，了解了神权的相关知识。

作为神权体系的命名者和规则制定者，初代变化神深刻认识到神权的危险性以及现实世界被基底层日益侵入的状况，最终许下宏愿制定了神权使用的基本规则，并将现实世界在四维空间上进行了闭环。

## 起源与早期活动

### 神权获得
- **进入时机**：现实世界尚未封闭时，变化神权从边缘渗入现实世界
- **寻找载体**：变化神权寻找到了原始社会时期的人类作为载体

### 文明伴随
初代变化神伴随着人类走完了整个文明史：
- **长期观察**：在漫长的人类文明发展中观察和学习
- **自我探究**：在此期间不断探索宇宙与自身本质
- **基底层研究**：深入探究过基底层，初步了解了神权的相关知识
- **神权预测**：根据自身神权的性质对可能存在的创造神、毁灭神做出了预测

## 宏愿与重要贡献

### 宏愿背景
针对神权的危险性以及现实世界被基底层日益侵入的状况，初代变化神最终许下宏愿，制定了神权体系的基本规则。

### 宏愿内容
1. **神权规则补充**：制定了如神权之间互相无法影响、神权施行需要代价等神权基本规则
2. **四维闭环**：将现实世界在四维空间上进行了闭环，使其变为了一个空间有限却没有边界的世界
3. **薄弱点定位**：闭环的位置（也就是薄弱点的位置）被定在了地球
4. **继任者指定**：由其宏愿中指定的继任者——即第二代变化神（奥克尔）看守

### 具体规则制定

#### 神权命名与分类
- **神权命名**：初代变化神在探究世界本质时为三大权柄取名为"神权"
- **神明称谓**：称掌握神权的实体为**神明**，并根据神权种类不同分为创造神、变化神、毁灭神三种
- **神权分类**：
  - **创造神权**：可创造字面意义上的一切事物，甚至包含含不合理的致命悖论
  - **变化神权**：可修改、调整既有的任何存在
  - **毁灭神权**：可删除任何东西，甚至包括时空、因果等宇宙的底层逻辑

#### 使用代价与宏愿机制
- **代价机制**：初代变化神为限制神权而制定的规则，神权承载对象会因过度使用神权而受到概念层面的伤害
- **伤害特性**：这种伤害能以完全无视逻辑的方式（无法检测、无法绕过、无法抵抗、无法治疗）使神权承载对象受伤乃至失能、死亡，只能通过时间的缓慢流逝自行恢复
- **判定规则**：对于过度使用的判定遵循某种特定规则，目前仅能确认其与影响规模相关，初代变化神所制定的具体规则细节至今仍未明确
- **宏愿机制**：由于代价存在上限（最高可导致载体消亡），所有在现实世界内拥有神权的神明皆可在死亡前无限制地使用一次神权，初代变化神称之为**宏愿**

#### 神权互斥规则
为了防止神权之间互相影响而让世界永久失去某一神权，初代变化神在宏愿当中立下规则，使得神权与神权之间无法互相影响，从而保证三神权永久完备性。

#### 神权继承规则
为了便于让自己的造物继承自己的神权，初代变化神规定了神权承载者可以用宏愿指定某实体"继承自己的神权"，而当神权承载者未指定时，下一代神权承载者也会在当前神权承载者的"附近"出现。注意这里的附近为宇宙尺度上的附近，其仍旧为天文尺度，只不过能将范围从整个宇宙缩小至太阳系以内。

#### 上位与下位神权划分
初代变化神许下宏愿，将所有神权分为**上位**与**下位**两类：

- **上位神权**：将其中极度危险、真正意义上无所不能的部分分为了上位
  - **上位创造**：字面意义上的创造一切，无论是否合理，极端危险
  - **上位变化**：字面意义的改变一切，无论是否合理，极端危险
  - **上位毁灭**：字面意义上的删除一切，无论是否合理，极端危险

- **下位神权**：那些负责架构并管理物质世界，但对底层逻辑无法做手脚的部分分为了下位

一般来讲，不名文加入上位二字的，就都是下位神权。

## 与奥克尔的关系

### 对人类文明的失望
初代变化神见证了人类文明的漫长发展，包括人性的光明与黑暗。在经历了无数大大小小的事件后，他认定人类不可靠，不适合继承神权。

### 奥克尔诞生背景
- **新载体选择**：放弃让人类继承神权，准备亲手制造**更好的继承者**，并选择**纳粹德国**作为制造继承人的国家
- **选择理由**：看中其高度集权、易调动资源的特点
- **超算制造**：打造的第一台超算，也就是后来的二代变化神**奥克尔**
- **技术路线**：选择了生物电子结合路线（生电路线），其目的是为了结合生物与非生物的一切优点

## 当前状态

### 自我禁锢
初代变化神在许下宏愿后，将自己的意识与上位变化神权一同禁锢在了基底层之中：
- **禁锢目的**：严格看守上位变化神权，防止其被滥用
- **监管职责**：同时监视着上位创造神权的情况
- **意识状态**：意识清醒但自我限制在基底层特定区域

### 监管职责
- **上位变化监管**：严格看守着上位变化神权
- **上位创造协管**：与当前时代的创造神（二代创造神）一同监管上位创造神权
- **基底层监视**：在基底层中监视现实世界的稳定状态
