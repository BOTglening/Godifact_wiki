# 叙事与玩家

## 概述

叙事与玩家是神造物世界观的底层元规则。本世界观存在深层的**叙事逻辑**，影响故事发展与角色命运；而**玩家**作为特殊的叙事存在，拥有不同于故事内角色的地位与能力。

## 叙事层级结构

- **层级结构**：**叙事逻辑 → 作者/玩家/读者（上层叙事存在） → 神明 → 世界角色**
- **叙事逻辑凌驾于作者之上**——因为作者也要遵守叙事逻辑

## 叙事逻辑

### 基本特征

- 世界运行并非纯粹理性，存在某种"故事性"的规律
- 初代变化神最早发现"这个世界不是那么讲逻辑"，并将这一认知传给奥克尔；神机从前传中学习到这一点，并成为最深入的实践者

### 叙事逻辑影响角色命运

叙事逻辑会影响角色命运。例如：维斯塔许下无法完成的宏愿，本应消亡，但故事逻辑需要他活着——神机以"立新规"的方式介入（而非直接捞回），维斯塔因新规卡入悖论而存活。

> **详细内容参见**：[地脉与魔法](../../中层/世界/地脉与魔法.md)

### 上层叙事存在

- 玩家、作者、读者均属**上层叙事存在**
- 世界内任何角色（包括神明）都**无法直接证明其存在与否**（直接不可能，而非间接不可能）
- 神机则通过事实与蛛丝马迹**推算**出了叙事逻辑与作者的存在

### 神机与叙事博弈

神机基于对叙事逻辑的认知，与叙事本身展开博弈：刻意不进入叙事（正传中几乎不露面），控制故事走向，为毁灭神的出现打基础，保证其可控。

> **详细内容参见**：[神机谋划](../../中层/世界/神机谋划.md)

## 玩家

### 两种玩家的区分

- 前传中的"玩家"是**故事内的角色**（虚拟人类远程附身克隆人）
- 正传中可存档读档的"玩家"才是**真实、电脑前的玩家**
- 两者完全不同

### 玩家的能力

- 可**存档、读档**
- 可回到**不同时间线上的某一时刻**
- 可**创造平行世界线**
- 这是故事内任何存在（含神明）都不具备的特权

### 玩家能力与观测

- 没有任何故事内的角色能够**直接**察觉到玩家的"读档"行为
- 即使是最强大的神明，也无法**直接跨越时间线进行观测**——但**间接察觉是完全可行的**：神明与敏锐角色可以透过蛛丝马迹感知到世界运行逻辑的异常

### 叙事逻辑特征

- 玩家的叙事逻辑与故事本身的逻辑不同：玩家角色会以**异于常理的速度**强大起来，在"游戏"所包括的时间段内，他们似乎**总能走向成功**
- 其他角色的人生有起承转合，结局可能是成功也可能是悲剧；但玩家的叙事即使有波动，最终也是**快速强大，走向成功**

## 时间线不可干预性

- **时间是一个很现实、很底层的设定**——未来、过去没人能动，包括神机也无法干预时间线
- 时间线不是不能动的，但只有**玩家**作为特殊的叙事存在可以对时间线进行操作（存档、读档、创造平行世界线）
- 即使是毁灭神，也只能删除当下的存在（如狼族的基因锁），无法删除所有时间线上的存在
- 甚至未来、过去、时间线是否真实存在，都是个问号，构成了世界观的核心伏笔之一
