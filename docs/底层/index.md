# 底层设定

## 概念诠释

底层设定是神造物世界观中的**基础元规则层面**，描述了世界的最根本结构和运作原理。这一层面构成了整个世界观的基础架构，中层和表层设定都建立在这些底层规则之上。底层设定揭示了世界的本质、起源和基本运行机制，是理解神造物世界观复杂性的关键。

底层设定可以被理解为"世界的源代码"——定义了世界的核心规则、约束和可能性边界，是世界观中最基础、最本质的部分。

## 定位与特点

**核心定位：**
- **基础架构**：为整个世界观提供基础规则和原理支持
- **元规则层面**：描述的是世界的元规则，而非具体现象或事件
- **影响全域**：底层设定的规则影响所有层面，从宇宙诞生到叙事逻辑

**主要特点：**
- **抽象性**：概念较为抽象，涉及世界本质和基本原理
- **普适性**：规则适用于世界观中的所有存在和现象
- **不变性**：底层设定通常被认为是不可改变的世界基础
- **系统性**：各概念之间存在紧密的逻辑联系

## 核心内容领域

底层设定主要涵盖以下几个核心领域：

### 1. 基底层与现实世界
描述世界的起源、结构与基本运作原理，包括基底层概念、现实世界诞生过程、地球作为薄弱点的定位等

> **详细内容参见**：[基底层与现实世界](规则/基底层与现实世界.md)

### 2. 神权体系
定义创造、变化、毁灭三大神权的本质、规则与运作机制，包括神权分类、使用代价、宏愿机制、上下位划分等

> **详细内容参见**：[神权体系](规则/神权体系.md)

### 3. 叙事与玩家
描述世界运行的元规则层面，包括叙事逻辑特性、玩家特殊性、时间线规则等

> **详细内容参见**：[叙事与玩家](规则/叙事与玩家.md)

### 4. 元层面人物

与底层规则直接相关的存在：创造现实的初代创造神、补完规则的初代变化神、删除一切的上位毁灭神（小白狼），以及身处概念性人类与游戏真相核心的林月。

> **详细内容参见**：[元层面人物](人物/index.md)

## 与世界观其他层面的关系

### 与中层设定的关系
- **基础与体现**：底层设定是中层的理论基础，中层是底层的具体应用和体现
- **抽象与具体**：底层是抽象规则，中层是具体实现和真相揭示
- **原理与现象**：底层解释原理，中层解释现象背后的真相

### 与表层设定的关系
- **规则与表象**：底层设定定义了表层世界运行的规则
- **本质与现象**：底层是世界本质，表层是现象表现
- **不可认知性**：福瑞种族无法直接认知底层设定内容

## 阅读建议

1. **先理解概念**：底层设定概念较为抽象，建议先理解基本概念框架
2. **交叉参考**：三个底层设定文档之间存在紧密逻辑联系，建议交叉阅读
3. **理解层次**：认识到这是世界的最基础规则，中层和表层都建立于此
4. **保持距离**：这些内容不应直接出现在表层叙事中，是"世界背后的代码"
