# 历史背景

> 本页收录的是**历史的真相版本**（中层历史）。表层流传的历史记载见[表层历史](../../表层/历史/index.md)——真相与记载的差异，正是本层的价值所在。

历史背景文档涵盖神造物世界观中从远古到当代的完整时间线。主线历史按时间顺序分为前传、间章与正传（福瑞时代）三段：前传是人类超算纪元的背景与剧情，间章是前传与正传之间的过渡，正传是福瑞时代的中层编年史。另有《火种故事》作为黑暗时代的故事化补全。

## 概念诠释

主线历史部分涵盖神造物世界观的核心历史脉络，按时间顺序分为前传、间章与正传（福瑞时代）三段：前传是人类超算纪元的背景与剧情，间章是前传与正传之间的过渡，正传是福瑞时代的中层编年史。

## 主要内容

### 1. 正传历史

福瑞时代的中层编年史：从共同体建立到当前鹿熊冷战时代的真实脉络，与表层历史三篇（共同体时期/黑暗时代/当前时代）一一对照。

> **详细内容参见**：[正传历史](正传历史.md)

### 2. 火种故事

《神造物·火种》故事概要：黑暗时代早期，普通生灵点燃第一簇反抗火种的故事。

> **详细内容参见**：[火种故事](火种故事.md)

### 3. 间章历史

前传与正传之间的过渡时期历史，包含神机登神、布局新世界的关键过程。

> **详细内容参见**：[间章历史](间章历史.md)

### 4. 前传历史

前传完整剧情线（林月视角）与前传关键机制。

> **详细内容参见**：[前传历史](前传历史.md)

### 5. 前传超算纪元

前传背景与"人物/技术志"：人类超算时代的核心背景、技术路线与核心超算角色档案。

> **详细内容参见**：[前传超算纪元](前传超算纪元.md)

## 阅读建议

1. **以史为纲**：建议先读[正传历史](正传历史.md)，与已读的表层历史逐段对照，再依次读火种故事 → 间章历史 → 前传历史 → 前传超算纪元
2. **随时跳出**：遇到提及的世界真相（神机谋划、地脉与魔法、太空巨构等）可跳至[中层世界真相](../index.md)相关条目，读完再回来
3. **注意层级**：越往前追溯越接近底层元规则，跨层链接均带徽标
