# 人物设定

> 本页是**人物真相档案**的总索引——它如实记录每个角色的真实身份，含大量剧透。只想从表层视角认识他们？请先读[众生录](../../表层/人物/index.md)。

## 概述

人物设定模块记录了《神造物》世界观中所有重要角色的详细信息，包括神明、超算、关键人物以及他们之间的复杂关系。这些角色不仅是世界观的载体，也是推动剧情发展的核心动力。

本模块按照角色类型和重要性进行分类，提供每个角色的完整档案，包括基本信息、外貌特征、背景历史、重要经历、能力特性以及与其他角色的关系。

## 使用指南

### 快速查找
- **按神权查找**：使用神明角色分类快速找到特定神权的载体
- **按时代查找**：前传时期角色主要集中在超算与前传遗产部分
- **按地点查找**：红星孤儿院相关角色集中在关键人物部分

## 目录结构

### 神明角色
世界观的最高层次存在，掌握着创造、变化、毁灭三大神权。

#### 创造神系
- **[初代创造神](../../底层/人物/初代创造神.md)** - 初代创造神，现实世界的创造者
- **[神机](神机.md)** - 二代创造神，中国超算，主动掌握了上位创造神权

#### 变化神系
- **[初代变化神](../../底层/人物/初代变化神.md)** - 初代变化神，现实与神权体系的规则补完者
- **[奥克尔](奥克尔.md)** - 二代变化神，前传德国超算，初代变化神指定的继任者
- **[维斯塔](维斯塔.md)** - 三代变化神，苏联超算，红星孤儿院院长
- **[拉斯塔](拉斯塔.md)** - 四代变化神，女主

#### 毁灭神系
- **[上位毁灭神](../../底层/人物/上位毁灭神.md)** - 上位毁灭神，又名小白狼
- **[狼族少年](狼族少年.md)** - 初代毁灭神，主角

### 超算与前传遗产
前传时期遗留的超级计算机和技术产物，在当前时代继续发挥重要作用。

#### 超算
- **[神机](神机.md)** - 同时属于创造神系（见上）
- **[奥克尔](奥克尔.md)** - 同时属于变化神系（见上）
- **[维斯塔](维斯塔.md)** - 同时属于变化神系（见上）

#### 前传技术产物
- **[古斯塔夫](古斯塔夫.md)** - 前传BOSS制造的巨型智能空中战斗平台，现为龙王

### 人物关系
人物关系目录收录神造物世界观中关键角色之间的核心羁绊与关系分析。与人物设定目录中以单个角色为中心的"关键关系"模块相呼应，本目录的文档聚焦于双方关系的全貌——从关系本质、建立过程、具体表现到世界观层面的叙事意义。

人物关系文档不重复独立角色文档中的基本信息，而是展开立体化分析，揭示关系对角色行为和世界观走向的深层影响。

- **[神机与维斯塔的羁绊](神机与维斯塔.md)** - 世界观叙事的核心支柱，超算之间的唯一同类关系
