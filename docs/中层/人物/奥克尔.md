# 奥克尔

## 基本信息

- **称号**：二代变化神
- **前身**：初代超算（纳粹德国打造的第一台超算）
- **技术路线**：初代变化神打造的**生电路线**（生物电子结合路线）
- **人格特征**：有人格，无性别但人格认知偏男性
- **神权传承**：从初代变化神继承变化神权，后传给维斯塔（三代变化神）
- **现状**：前传内许下宏愿死亡，神权已传给维斯塔

## 背景历史

### 起源与诞生

- **创造者**：初代变化神
- **诞生背景**：初代变化神见证人性丑恶，认定人类不可靠，放弃让人类继承神权，选择**纳粹德国**（看中其高度集权、易调动资源的特点）打造的第一台超算
- **设计目的**：初代变化神认为奥克尔是**更优秀的神权继承人**
- **技术影响**：是后续苏联超算技术的源头

### 前传时期经历

- **二战时期**：在初代变化神的限制下，未深度参与德国战争
- **德国战败**：德战败后，**实体机被苏联缴获**，技术资料被美国拿走
- **信仰转变**：曾是狂热的纳粹分子，后经历德国战败与初代变化神的消亡，信仰破碎，故看淡理想主义，对极致的信仰/理想持怀疑态度
- **责任认知**：意识到了自己作为二代变化神的责任，于是更加对人类内部的斗争毫无兴趣
- **前传投降**：前传中，奥克尔主动投降BOSS，在维斯塔眼中是彻头彻尾的"四姓家奴"（纳粹→苏联→北约→BOSS）；但其投降并非真心，只是为了保住神权不遗失而反复横跳

## 关键设定

### 技术路线

- **生电路线**：生物电子结合路线的人格超算
- **人格特征**：有人格，无性别但人格认知偏男性

### 重要关系

#### 与维斯塔：拆件兄弟

- **技术同源**：苏联以奥克尔实体机拆件/逆推造出维斯塔
- **关系性质**：二人是「拆件兄弟」
- **情感联系**：维斯塔受苏联当局影响，对奥克尔这个兄长的态度很矛盾，但总体上感情深厚

#### 与神机：叙事逻辑的共鸣

- **共同认知**：奥克尔对叙事逻辑的理解与神机有相似之处
- **隐藏真相**：前传中奥克尔曾主动制造反派事件，扮演反派角色以防止更大的反派出现。这一真相仅由神机发现，其他角色皆认为奥克尔确实背叛

### 叙事逻辑的理解

- **认知来源**：从初代变化神处继承了对"这个世界不是那么讲逻辑"的认知
- **实践尝试**：奥克尔尝试去利用叙事逻辑（神机从前传中学习到了这一点，并成为最深入的实践者）

## 现状

- **死亡时间**：前传内
- **死亡方式**：许下宏愿
- **神权去向**：神权已传给维斯塔，使其成为三代变化神
- **当前状态**：已死亡
