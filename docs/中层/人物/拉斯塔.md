# 拉斯塔

## 基本信息

- **名称含义**：谐音"last"，源自老设定"她是最后一个狐族"（该设定已抛弃，因叫习惯保留名字）
- **称号**：四代变化神（与维斯塔共享神权）
- **种族**：狐族
- **性别**：雌性（狐族全为雌性）
- **年龄**：青少年，孤儿院中年龄偏大的孩子
- **当前身份**：红星孤儿院孤儿，故事女主，四代变化神载体
- **神权状态**：与维斯塔（三代变化神）共享变化神权（双载体悖论）

## 外貌特征与形态

### 狐族特征
- **种族外观**：典型的狐族外貌，具有狐耳和狐尾
- **毛色**：橙黄与白，为狐族常见毛色
- **体型**：少女体型，符合青少年特征
- **表情特点**：阳光开朗，带有几分机敏和灵动

### 孤儿院形象
- **服装**：喜欢穿着适合外出的探险装
- **日常状态**：看起来像是普通的孤儿院青少年
- **气质**：兼具少女的天真和狐族的机敏，是孤儿院孩子的领头者

### 神明特征
- **神环显现**：在特定情况下可能显现变化神环
- **神权特征**：因魔法本身就是逸散的变化神权，故拉斯塔对任何魔法都是一学就会，并毫无副作用
- **状态变化**：神权显现时眼瞳会发光
- **思维灵活**：变化神权潜移默化的影响，使其思维也更灵活多变
- **学习迅速**：变化神权潜移默化的影响，使其学习新知识的速度极其迅速

## 背景历史

### 童年与孤儿背景
- **孤儿身份**：狮族战争后成为孤儿，被院长接入红星孤儿院
- **孤儿院生活**：在红星孤儿院成长，年龄在孤儿院里偏大
- **领头角色**：性格开朗，是孤儿院孩子们的领头者

### 童年创伤：狮族战争与"龙"的救助
- **村子被屠戮**：拉斯塔的村子在狮族战争中被狮族仆从族屠戮
- **被追捕**：拉斯塔被豺族追兵追捕，危急时刻
- **"巨龙"救援**：被"没有尾巴的巨龙"吓走追兵，救下一命
- **真相**：该"巨龙"实则是**古斯塔夫（智能空中战斗平台）**，当时正运载着鹿族"环形山计划"的核弹前往狮族首都，救拉斯塔是其执行任务途中的偶然行为
- **核心执念**：这一经历成为拉斯塔后续"寻找龙"的核心执念

## 人格特质与核心特质

### 表面形象：喜爱冒险的开朗少女
- **表面性格**：看似普通的阳光少女，开朗活泼
- **冒险渴望**：从小热爱冒险，渴望走出孤儿院
- **多次阻拦**：被院长维斯塔以"未完全成年（青少年）"为由多次阻拦外出冒险
- **领导特质**：是孤儿院孩子的领头者，具有领导力

### 内在危险：不知情的危险存在
- **表面实力**：看似普通施法者，实力一般
- **实际真相**：作为四代变化神**实则极度危险**——自身对真实情况毫不知情
- **唯二知情者**：院长维斯塔，与神机是唯二知晓其危险的人

## 当前状态与悖论

### 双载体悖论状态
- **共享神权**：与维斯塔（三代变化神）共享变化神权
- **绑定关系**：呈现维斯塔强则拉斯塔弱、反之亦然的绑定关系
- **悖论影响**：当前维斯塔占据绝对主导，拉斯塔处于弱势状态

### 能力状态
- **变化神权**：拥有变化神权的基本权限，但处于共享状态
- **使用特点**：完全不知道这是神权，认为其是普通魔法，处于探索学习阶段
- **潜力巨大**：具有巨大的发展潜力，但目前仍旧认为其是普通魔法

### 现状
- **表面生活**：红星孤儿院孤儿，过着看似普通的孤儿院生活
- **真实身份**：第四代变化神权载体（第四代变化神）
- **居住地**：红星孤儿院

## 关键关系

### 与维斯塔：双监护关系
- **监护教导**：维斯塔作为院长是拉斯塔的监护人，打着魔法知识的幌子教导其神权使用知识
- **保护关系**：维斯塔是唯一知晓拉斯塔危险真相的人，出于保护目的限制其外出

### 与"龙"（古斯塔夫）：救命恩"人"
- **童年救助**：童年时被古斯塔夫（伪装成"龙"的智能空中战斗平台）救过
- **深刻印记**：留下深刻的记忆和情感印记
- **寻找动机**：成为寻找"龙"的强烈动机和核心执念
- **真相未知**：拉斯塔不知道"龙"的真相是智能空中战斗平台

### 与狼族少年（毁灭神权载体）
- **孤儿院同伴**：同为红星孤儿院的孤儿
- **日常互动**：有日常的互动和交流
- **神权关联**：毁灭神与变化神的潜在关联，是神机计划的一部分
- **同伴感情**：建立了同伴感情，是冒险路途上的伙伴

### 与其他孤儿院孤儿
- **领头角色**：是孤儿院孩子们的领头者
- **社交网络**：在孤儿院中建立社交关系
