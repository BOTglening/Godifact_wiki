# 中层设定

## 概念诠释

中层设定是神造物世界观中的**中间认知层面**，位于表层福瑞世界的直观认知与底层神权体系的抽象概念之间。这一层面揭示了表层世界所不知晓的真相，但又不会直接触及世界观最底层的核心逻辑。

中层设定可以被理解为"世界背后的真相"——福瑞种族生活在一个精心设计的表象之下，而中层设定则揭示了这一表象背后的机制、历史、技术和深层关联。

## 定位与特点

**核心定位：**
- **桥梁作用**：连接表层现象与底层逻辑的桥梁
- **真相揭示**：揭示表层福瑞世界无法认知的深层事实
- **认知过渡**：帮助理解从表象到本质的认知过渡

**主要特点：**
- **解释表象**：既有福瑞世界可观察的部分事实，又包含他们无法理解的深层机制
- **技术内涵**：大量涉及前传、间章时期遗留的技术和设施
- **历史真相**：揭示共同体时期、黑暗时代等历史事件的真实背景
- **角色动机**：展现神明、关键人物的真实意图和计划

## 主要内容领域

中层设定主要涵盖以下几个核心领域：

### 一、世界真相

#### 1. 历代三神谱系
提供神权传承脉络和历代神明的基本信息索引，建议作为中层阅读的起点。

> **详细内容参见**：[历代三神](世界/历代三神.md)

#### 2. 地脉与魔法系统
揭示魔法力量的真正来源、地脉的本质以及法师体系的深层机制

> **详细内容参见**：[地脉与魔法](世界/地脉与魔法.md)

#### 3. 神机谋划与布局
展现神机作为幕后掌控者的完整计划、太空战略和对世界的时间线掌控

> **详细内容参见**：[神机谋划](世界/神机谋划.md)

#### 4. 太空巨构与设施
描述地球外的巨型构造物（银河之眼、克隆仓库、月球平台等）及其战略意义

> **详细内容参见**：[太空巨构](世界/太空巨构.md)

#### 5. 太空清除计划
揭示神机与维斯塔为了控制毁灭神而采取的重大太空战略决策

> **详细内容参见**：[太空清除计划](世界/太空清除计划.md)

#### 6. 特殊地点真相
揭示地球内重要地点（世界树、梯形神殿、红星孤儿院等）的真实历史和技术内涵

> **详细内容参见**：[特殊地点](世界/特殊地点.md)

#### 7. 龙族真相
展现龙族的真实能力、压制机制以及相关伏笔

> **详细内容参见**：[龙族真相](世界/龙族真相.md)

### 二、历史真相

主线历史涵盖神造物世界观的核心历史脉络，按时间顺序分为前传、间章与正传（福瑞时代）三段：前传是人类超算纪元的背景与剧情，间章是前传与正传之间的过渡，正传是福瑞时代的中层编年史。另有《火种故事》作为黑暗时代的故事化补全。

- **正传历史**：福瑞时代的中层编年史——从共同体建立到当前鹿熊冷战时代的真实脉络，是表层历史三篇（共同体时期/黑暗时代/当前时代）的真相版
- **火种故事**：《神造物·火种》故事概要——黑暗时代早期，普通生灵点燃第一簇反抗火种的故事
- **间章历史**：前传与正传之间的过渡时期历史，包含神机登神、布局新世界的关键过程
- **前传历史**：前传完整剧情线（林月视角）与前传关键机制
- **前传超算纪元**：前传背景与"人物/技术志"——人类超算时代的核心背景、技术路线与核心超算角色档案

> **详细内容参见**：[历史真相总览](历史/index.md)

### 三、人物真相档案

神明、超算与众生背后不为人知的真实档案——表层众生录中那些人物（维斯塔、拉斯塔、狼族少年、古斯塔夫、龙鹿等）的真实身份，以及从未在表层露面的存在（神机、奥克尔），都在这里。

> **详细内容参见**：[人物真相档案](人物/index.md)

## 与世界观其他层面的关系

### 与表层设定的关系
- **解释表象**：中层设定解释表层现象背后的原因
- **提供背景**：为表层事件提供深层历史和技术背景
- **限制认知**：福瑞种族无法直接认知中层设定内容

### 与底层设定的关系
- **具体应用**：中层设定是底层神权体系和基底层概念的具体应用
- **技术实现**：展现底层概念在现实世界的技术实现形式
- **有限揭示**：不会直接触及神权体系的本质，而是展现其外在表现

## 阅读建议

1. **先表层后中层**：建议先了解表层设定的基本框架，再探索中层真相
2. **两条路径任选**：
   - **机制路线**（推荐给想先搞懂"世界怎么运转"的读者）：历代三神 → 地脉与魔法 → 神机谋划 → 太空巨构 → 太空清除计划 → 特殊地点 → 龙族真相
   - **以史为纲**（推荐给刚读完表层历史、想逐条对答案的读者）：正传历史（与表层历史一一对照）→ 火种故事 → 间章历史 → 前传历史 → 前传超算纪元，途中遇到的世界真相条目随时跳出阅读
3. **交叉参考**：中层设定各文档之间存在密切联系，建议交叉阅读
4. **理解层次**：认识到这是"世界背后的真相"，而非福瑞角色的认知
