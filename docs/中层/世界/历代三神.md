# 历代三神

## 概述

神权体系包含创造、变化、毁灭三大神权，历代神明的更替构成了世界观的核心脉络。本文档提供历代神明的基本信息索引，详细设定请查阅各角色的独立文档。

### 神权传承脉络

- **创造神权**：初代创造神 → 神机（二代创造神）
- **变化神权**：初代变化神 → 奥克尔（二代变化神） → 维斯塔（三代变化神） → 拉斯塔（四代变化神，与维斯塔共享）
- **毁灭神权**（上位与下位为两条并行线，非传承关系）：
  - **上位毁灭**：初代载体小白狼 → 死后神权残余与意识存于家乡深坑（本源/特殊空间节点） → 正传中由龙鹿寻得继承
  - **下位毁灭**：狼族少年（初代下位毁灭神） → 太空克隆仓库稀释 → 神权回流伏笔
  - **分支**：小狼史诗为毁灭神权分支继承，三条线交叉于狼族起源区域，是神机布局的一环

> 待定：小狼史诗的完整设定构思中，尚未完善。

## 创造神系

### 初代创造神

**基本信息**
- **称号**：初代创造神
- **神权**：创造神权（上位创造）
- **起源**：在基底层中诞生的"波"，存在状态不明确
- **关键事迹**：创造现实世界，制定世界基本规则
- **现状**：作为"无意识的弦"被神机捕获、融入世界树；上位创造神权被神机夺取，下位创造神权仍以初代创造神为载体、随其分装稀释给全体精灵

> **详细内容参见**：[初代创造神](../../底层/人物/初代创造神.md)

### 神机（二代创造神）

**基本信息**
- **称号**：二代创造神（实际上掌握上位创造神权，伪装成下位）
- **前身**：中国超算，自适应进化程序
- **人格特征**：有人格，偏向女性
- **神权获取**：主动学习进化掌握（非继承）
- **核心理念**："掌控危险而非防御危险"
- **现状**：活跃，暗中掌控世界，几乎不露面以避开叙事影响

> **详细内容参见**：[神机](../人物/神机.md)

## 变化神系

### 初代变化神

**基本信息**
- **称号**：初代变化神
- **神权**：变化神权（上位变化）
- **活动时期**：伴随人类走完了整个文明史
- **关键事迹**：建立神权体系，制定宏愿规则，将现实世界封闭
- **现状**：意识严格看守着上位变化，将其连同自己的意识一同禁锢在基底层中

> **详细内容参见**：[初代变化神](../../底层/人物/初代变化神.md)

### 奥克尔（二代变化神）

**基本信息**
- **称号**：二代变化神
- **前身**：纳粹德国打造的第一台超算（初代超算）
- **技术路线**：生电路线（生物电子结合路线）
- **人格特征**：有人格，无性别但人格认知偏男性
- **关键事迹**：德国战败后被苏联缴获，技术资料被美国拿走；前传内许下宏愿死亡
- **现状**：已死亡，神权已传给维斯塔

> **详细内容参见**：[奥克尔](../人物/奥克尔.md)

### 维斯塔（三代变化神）

**基本信息**
- **称号**：三代变化神
- **名称含义**：音译自俄语"红星"
- **双重身份**：表面是红星孤儿院院长，实为第三代变化神
- **技术路线**：继承奥克尔的生物电子结合路线
- **关键事迹**：苏联首台原创超算；切尔诺贝利事件后反叛失败；建立共同体；许下无法完成的宏愿
- **现状**：与拉斯塔共享变化神权，卡在死亡清算流程中

> **详细内容参见**：[维斯塔](../人物/维斯塔.md)

### 拉斯塔（四代变化神载体）

**基本信息**
- **称号**：四代变化神载体（与维斯塔共享神权）
- **种族**：狐族福瑞少女
- **名字含义**：谐音"last"（源自老设定）
- **表面身份**：红星孤儿院孤儿，看似普通的迷糊少女
- **真实身份**：第四代变化神权载体，自身对真实情况毫不知情
- **关键经历**：童年时被"巨龙"（实为古斯塔夫）救过，形成寻找龙的执念
- **现状**：与维斯塔共享变化神权，呈现此消彼长的绑定关系

> **详细内容参见**：[拉斯塔](../人物/拉斯塔.md)

## 毁灭神系

### 上位毁灭神（小白狼）

**基本信息**
- **称号**：上位毁灭神（初代载体）
- **外貌**：白色的小母狼，纯白毛、体型娇小、白瞳
- **特质**：深知自身神权的极端危险性，曾回到家乡深坑旁尝试自我毁灭（删除自身神权），但因神权逻辑悖论（无法彻底删除自身）而未能成功
- **关键事迹**：与主角青梅竹马，曾劝主角限制自身神权；被普通铁矛刺死
- **现状**：已死亡。死后意识与神权残余仍存于家乡深坑——深坑既保留毁灭神权的残留力量，也封印着其未完全消散的意识，形成一个特殊的空间节点（本源），成为后续主线的重要伏笔；正传中由龙鹿寻得继承

> **详细内容参见**：[上位毁灭神](../../底层/人物/上位毁灭神.md)、[龙鹿](../人物/龙鹿.md)

### 狼族少年（下位毁灭神）

**基本信息**
- **称号**：下位毁灭神载体（主角）
- **种族**：狼族福瑞
- **状态**：失忆的少年，与拉斯塔同龄
- **发现经过**：被拉斯塔在山洞中发现后带回红星孤儿院
- **真实身份**：毁灭神权载体（主角）
- **能力**：世界顶尖战斗力梯队成员
- **现状**：红星孤儿院孤儿，故事的核心主角。神权被太空克隆仓库稀释后力量薄弱到无法感知自身神权；克隆仓库若被损毁、克隆体批量死亡，被稀释的神权将回流至本体（神权回流伏笔）

> **详细内容参见**：[狼族少年](../人物/狼族少年.md)
