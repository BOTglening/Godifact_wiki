# 太空清除计划

## 概述

太空清除计划是神机与维斯塔在间章时期做出的重大战略决策，旨在通过清除地外智慧物种来防止毁灭神在其他星系出现。这一计划体现了神机"掌控危险"核心理念的极端应用，也反映了维斯塔作为变化神的决断力。本文档揭示清除计划的背景、执行方式、相关事件以及对世界观的影响。

## 清除计划的背景与动机

### 根本动机：防止毁灭神扩散

**毁灭神的危险性：**
- **神权特性**：毁灭神权具有极强的破坏性和不可控性
- **星系扩散风险**：如果毁灭神在其他星系出现，将造成无法控制的跨星系灾难
- **预防性措施**：为避免这种风险，需要采取极端预防措施

**神机与维斯塔的共同决策：**
- **根本动机**：为防止毁灭神在其他星系出现，神机与维斯塔做出了清除所有地外智慧物种的决定
- **责任共担**：两位神明共同承担这一残酷决定的责任

## 清除计划的执行方式

### 清除行动流程

**发现与评估：**
- **监控系统**：利用银河之眼等监控设施监控银河系，发现地外智慧物种

**执行清除：**
- **主动出击**：与发现的太空文明主动交战
- **灭绝策略**：大部分直接灭绝，可能留数据存档
- **效率优先**：以最高效率执行清除，避免长期消耗战

### 数据保存与记录

- **数据保存**：大部分直接灭绝，可能留数据存档

## 天穹破碎事件

### 事件背景

**太空扩张时机：**
- **间章登神之后**：神机是在**间章登神之后**才开始大规模向太空扩张的
- **前期限制**：登神前，其势力范围局限于地月系以内，受限于资源和技术
- **仓促扩张**：急迫地"争时间"，为了布局毁灭神的出现和控制范围，扩张行动较为仓促

> **详细内容参见**：[间章历史](../历史/间章历史.md)

**遭遇外星文明：**

**超距作用技术文明：**
- **意外发现**：急促的扩张导致被一个掌握**超距作用**技术的外星文明发现
- **技术震惊**：该文明的技术完全超出了地球科技的认知范围

**超距技术特点：**
- **基底层应用**：基于对**基底层**的应用，实现了违背相对论的能力：
- **超光速移动**：实现了超光速移动，突破了传统物理限制
- **超距传输**：实现了空间跃迁式的超距传输
- **超距武器**：具有无视距离，指哪打哪的超距武器

**技术对抗劣势：**
- **防御困境**：超距武器极其诡异，防不胜防。当时地球科技完全无法防御
- **技术代差**：暴露了地球科技与先进外星文明之间的巨大代差
- **唯一优势**：前传BOSS遗留的**特殊材料**，凭借其超乎想象的强度，能够硬扛几发超距武器的攻击

### 太阳系之战

**战争性质：**
- **最大挫败**：这是神机所遭受的**最大挫败之一**，影响了后续的太空战略

**战争过程：**
- **创造神权应用**：神机利用其创造神权（可先有结果再补过程，甚至紧急制造悖论）以诡异的速度进步和反击
- **战争范围**：外星文明入侵太阳系，从冥王星一路打到地球轨道，神机再将战线推回冥王星
- **激烈对抗**：战争范围横跨整个太阳系，形势一度极为危急

**结局与影响：**
- **成功击退**：神机最终在**地月系**击退了外星入侵者，将其势力彻底赶出太阳系
- **战略调整**：此后，她向宇宙的探索变得**更加谨慎**，不再冒进
- **技术应用**：战后，月球武器平台的光束融合了**超距作用**原理

### 事件表象与真相

**福瑞世界的认知：**
- **发生时间**：建国22年
- **表象描述**：天空忽然破碎，变成一块块时不时变黑的巨大六边形，一块六边形以及一个大约是圆柱体或长方形的东西掉了下来
- **短暂现象**：焰种短暂出现
- **最终结果**：灾难被神明解决，焰种再没有人见过

**中层真相：**

**天穹破碎的真实由来：**
- **飞船坠毁**：战斗中，一艘外星飞船坠毁，撞上了神机为掩饰自己改造太阳系动作而制造的**天幕**
- **事件形成**：形成"天穹破碎"事件，被福瑞种族误解为天灾
- **焰种的结局**：坠毁飞船上的外星种族——**焰种**（接触氧气即自燃，因死亡时燃烧被贬称为"焰种"）——短暂出现后，残部逃窜伪装当地原住民企图生存延续，但太空战争结束后被神机的精灵部队搜查猎杀殆尽——因为不能让他们牵扯到故事里

**天幕的作用：**
- **掩饰功能**：神机制造天幕以掩饰自己对太阳系的改造动作
- **模块化设计**：由巨大的六边形模块构成，六边形是人工天幕的原生几何结构
