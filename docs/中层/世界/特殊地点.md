# 特殊地点

## 概述

本文档描述世界观中地球内部的重要特殊地点，揭示这些地点背后的真实历史、功能和技术内涵。这些地点在表层福瑞世界中有着不同的认知和传说，但中层视角揭示了它们作为神机计划组成部分的真实本质。

## 主要特殊地点

### 世界树

#### 表层认知（福瑞视角）

- **地点**：喜马拉雅山附近
- **表象**：巨大的树木状结构，散发神秘光芒
- **传说**：传说中连接天地的神树，蕴含无尽智慧
- **历史**：曾在共同体时期发挥作用
- **现状**：已毁，只剩下残骸

#### 深层真相（中层视角）

**建造目的与性质：**
神机在喜马拉雅山附近建造了**世界树**——一个巨构信息收集中枢。

**技术架构与功能：**
- **计算核心**：行星级别的信息上下行枢纽，收集、处理整个地球的数据
- **意识节点**：精灵族是其意识节点，所有精灵族通过世界树意识共通，都是一个个体
- **镇压维护地脉**：地脉灾难之前，地脉源头一直被精灵们借由世界树**镇压维护**，故地脉始终处于相对平稳的状态；地脉灾难后世界树断裂、精灵失去镇压之力，地脉才开始愈发明显地蔓延，缓慢地撕裂福瑞们生活的大陆

**精灵族连接机制：**
- **意识网络**：精灵族通过世界树共享意识，形成统一的思维网络
- **生物处理器**：精灵族作为生物传感器，帮助世界树获取信息
- **网络核心**：世界树构成精灵族共同网络的核心节点

**毁灭原因与影响：**
- **地脉灾难**：地脉灾难将世界树摧毁了
- **网络断裂**：导致精灵族共同网络断掉，精灵族变成个体思维
- **波及最小**：共同体只是被地脉灾难波及最小的地方，真正冲击目标是北美洲与喜马拉雅（世界树）
- **社会影响**：精灵族从统一的意识网络变为个体思维，对精灵族社会结构产生深远影响

**未重建的深层考量：**
- **技术判断**：通过叙事逻辑，神机预测其修了还会被毁，而且到时候会有更大的故事，波及更多事情
- **替代方案**：神机放弃了世界树，转而用银河之眼等替代方案监控

### 梯形神殿

#### 表层认知（福瑞视角）

- **历史地位**：共同体时期的核心建筑，神明住所，政治中心
- **建筑特点**：独特的梯形结构，宏伟壮观
- **历史事件**：天穹破碎事件（建国22年）中神环首次显现的地点
- **现状**：连同旧首都一同沉入水下，成为水下遗迹

#### 深层真相（中层视角）

**建造目的与功能：**
- **政治象征**：作为共同体政治统一的象征，维斯塔统治的标志性建筑
- **技术中心**：隐藏着高级技术设施，包含神明的先进技术
- **仪式场所**：重大仪式和活动的举办地

**技术特点与遗产：**
- **结构设计**：梯形结构具有特殊的技术意义，其本质是苏式大型生电超算基座，接入人格核心后就是完整的超算
- **超算摄政**：能够辅助维斯塔对日益庞大的共同体进行更精准快速的统筹规划
- **信息存储**：存储共同体时期的几乎一切信息，包含全部技术与知识，以及神明的种种规划

**鹿族的精神控制技术起源：**
鹿族利用梯形神殿遗留技术与魔法结合，开发出精神控制能力：
- **技术基础**：基于梯形神殿的思维互联技术进行研究和改进
- **魔法融合**：与变化神权溢散的魔法结合，形成独特的精神控制体系
- **控制机制**：对法师与奴隶官进行一对一长期精神控制，增强管理效率
- **副作用**：使用者被迫忍受"颅内炸裂的噪音"

**沉没原因与深层意义：**
- **地脉影响**：受地脉灾难与鹿族复活神明失败而影响，最终地壳变动导致沉没
- **历史转折**：共同体崩溃的标志性事件，象征着一个时代的结束

### 红星孤儿院

#### 表层认知（福瑞视角）

- **建立者**：维斯塔建立的孤儿院
- **功能**：收容孤儿，提供教育和庇护
- **角色**：故事起点，卧虎藏龙之地
- **重要性**：核心角色聚集的地方
- **现状**：正常运营，收容各族孤儿

#### 深层真相（中层视角）

**建立背景与动机：**
- **真正的目的**：神机的控制毁灭神计划，以及维斯塔退休计划的起点
- **附带作用**：让感觉“新时代不需要我”的维斯塔有个去处，维护其心理状况
- **计划的节点**：是神机与维斯塔所有计划的一个重要节点，故意汇聚关键角色的地方

**特殊性质与功能：**
- **种族汇聚**：汇聚各种族的特殊个体，打破种族界限
- **神明技术**：藏匿着关键的技术知识，甚至有未被广大福瑞发现的技术

**关键角色与战略地位：**
- **维斯塔**：三代变化神，院长，表面身份是孤儿院管理者
- **狼族少年**：毁灭神载体，失忆的主角，故事的核心触发者
- **拉斯塔**：四代变化神载体，狐族少女，与维斯塔共享神权
- **甲族幸存者**：知道甲族被灭真相的幸存者，掌握重要历史信息
- **其他种族**：各种族的特殊个体，每个人都有独特的故事和价值
